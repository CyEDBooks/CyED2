## Presentación

Este book interactivo reúne el material de estudio de **Computación y
Estructuras Discretas II**: relaciones de equivalencia y conjuntos
parcialmente ordenados, recurrencias e inducción matemática, divide y
vencerás, teoría de números, y programación funcional en Scala.

## Cómo usar este book

Para cada unidad:

1. Lea el material de estudio y reproduzca los ejemplos resueltos.
2. Complete el conjunto de ejercicios.
